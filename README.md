# HMPS TRPL POLMED — Official Web Portal

Portal digital resmi **Himpunan Mahasiswa Program Studi Teknologi Rekayasa Perangkat Lunak (HMPS TRPL)** Politeknik Negeri Medan. 

Platform ini berfungsi sebagai pusat informasi, wadah transparansi kepengurusan, serta media publikasi karya dan kegiatan mahasiswa TRPL.

---

## Gambaran Umum

Website ini dirancang sebagai gerbang komunikasi modern yang menghubungkan mahasiswa, alumni, dan masyarakat luas dengan berbagai program kerja himpunan. Melalui antarmuka yang bersih dan interaktif, portal ini menyajikan:

- **Profil & Sejarah Organisasi**: Informasi arah gerak himpunan, nilai dasar, serta visi dan misi.
- **Struktur Kepengurusan**: Dokumentasi divisi aktif dan susunan pengurus antar periode.
- **Publikasi Berita & Kegiatan**: Informasi kegiatan pengabdian masyarakat, turnamen, dan agenda akademik.
- **Galeri Video & Edukasi**: Kurasi workshop pengembangan perangkat lunak, game development, dan webinar teknologi.
- **Karya & Artikel**: Wadah literasi digital serta publikasi artikel teknis mahasiswa.

---

## Teknologi

Aplikasi ini dikembangkan menggunakan ekosistem **Next.js** modern dengan fokus pada performa tinggi, kemudahan navigasi, dan pengalaman pengguna yang responsif di berbagai perangkat.

- **Next.js (App Router)**: Fondasi framework untuk manajemen rute dan dynamic rendering.
- **React & TypeScript**: Membangun antarmuka modular dengan keandalan tipe data yang aman.
- **Design System**: Tampilan modern yang adaptif dengan dukungan tema terang dan gelap.

## Menjalankan Proyek

### 1. Instalasi Dependensi
```bash
bun install
# atau
npm install
```

### 2. Mode Pengembangan (Development)
```bash
bun dev
# atau
npm run dev
```
Akses portal melalui peramban di `http://localhost:3000`.

### 3. Kompilasi Produksi (Production Build)
```bash
bun run build
bun start
# atau
npm run build
npm start
```
